## 過去の実装状況（会話記録と現行コードに基づく要約）

以下は網羅的なコミット履歴ではなく、現時点で引き継ぐべき主要な実装・検証内容。

- 通常版とSync V2を統合した `index-integrated.html` を開発版に用意。
- PBKDF2-HMAC-SHA256 310,000回 + AES-GCM-256のローカル暗号化を実装。
- 暗号化バックアップと復元を実装。過去の会話では通常バックアップ作成・復元・再同期、および誤パスワード時に元データが変更されないテストを実施したとの報告あり。
- Worker経由の暗号化クラウド同期、revision管理、競合検出、自動保存・定期確認を実装。
- WebLLMとQwen3-4Bを統合。Qwen3-8BはiPad Safariでクラッシュした過去事例があり、4Bを推奨。
- AI推論後の記憶候補抽出は、推論エンジンを二度呼び出さない同期ルール方式へ変更。
- 挨拶への短い定型応答、会話履歴の直近12件制限、生成設定の調整を実施。
- 2026-11-04の会話で、ユーザーは「1＋1は？」への「2」の応答、味噌ラーメンの好みの記憶候補抽出・承認、再ログイン後の想起、長期記憶画面への登録を確認したと報告。
- 一時期、応答生成エラーやログイン不具合が発生し、開発版で修正・再テストを実施。現行コードではQwen3の思考モードを無効化する `extra_body: { enable_thinking: false }` が設定されている。
