# ALVIS 完全オフライン受け入れ試験

## 目的

「一度オンラインで準備した後、インターネットを完全に切ってもALVISが独立して使える」ことを実機で確認する。Service Workerの登録やキャッシュ件数だけでは合格にしない。

## 合格条件

すべてiPad Pro M1 / Safariで確認する。各項目を実際に実行し、結果・日時・iPadOS/Safariバージョンを記録する。

- [ ] オンライン状態で開発版ALVISを開き、アプリ本体と依存コードを一度読み込む。
- [ ] Qwen3-4Bを最後までロードし、短い質問に正しい日本語で回答できる。
- [ ] Kokoro TTSを利用する場合は、音声モデル/辞書を一度ロードして試聴する。標準音声も別に確認する。
- [ ] 保管庫にログインし、テスト用の会話と承認済み記憶を保存する。
- [ ] Safariのタブを閉じる。可能ならPWAを終了して再起動する。
- [ ] 機内モードを有効にし、Wi-Fi/モバイル通信が無効であることを確認する。
- [ ] ALVISをホーム画面のアイコンまたはSafariから再度開く。アプリ画面が表示される。
- [ ] 保管庫へログインでき、直前の会話・記憶が復号されて表示される。
- [ ] Qwen3-4Bを読み込める。モデル取得待ちやネットワークエラーで停止しない。
- [ ] 新しい質問へローカル回答できる。
- [ ] 過去の承認済み記憶を質問に応じて参照できる。
- [ ] 標準音声読み上げが動く。Kokoroを使う場合はKokoroも動く。
- [ ] 新しい会話を保存し、ページを再読み込みしても保持される。
- [ ] オフライン中にオンラインAI連携を明示選択しても、通信失敗後にローカルQwenへ戻り、アプリ全体が停止しない。
- [ ] 機内モードを解除すると、既存の同期機能がユーザー設定に従って正常に再接続する。同期競合が発生した場合は自動上書きせず停止する。

## 不合格・要調査条件

- アプリの再起動後にHTML/CSS/JavaScript/WASM依存がネット接続を要求する。
- モデルキャッシュが消えており、Qwenを再ロードできない。
- 保管庫データが消える、復号できない、または古いデータに巻き戻る。
- TTSだけでなく、ローカルチャットまでネットワーク待ちになる。
- オンラインAIのタイムアウトがローカル推論を妨げる。
- 機内モード解除後に同期が競合データを無断で上書きする。

## 安全上の注意

- 試験前に最新の暗号化バックアップをエクスポートする。
- 本番データを使った破壊試験・削除試験は行わない。テスト用の会話と記憶を使う。
- 保管庫パスワード、同期トークン、OAuthトークンをスクリーンショットやログに含めない。
- ブラウザのサイトデータ削除、PWA再インストール、キャッシュ消去はこの試験の一部にしない。これらはモデルキャッシュを消す可能性がある。
- 試験が完了するまでは「完全オフライン対応済み」と表現しない。
